# 🚌 Shuttle Pass Renewal System

A standalone web application for managing member shuttle passes, auto-generating monthly serial numbers, and performing 1-click bulk monthly pass renewals.

## 🚀 How to Run (Windows)

1. Open the folder **`shuttle-pass-system`** on your Desktop.
2. Double-click **`START.bat`**.
3. The app will start locally and automatically open in your web browser at `http://localhost:3000`.

---

## ✨ Features Included

- 🎫 **Monthly Card Management**: Create, edit, and search shuttle passes with auto-formatted monthly serials (`SP-YYYY-MM-001`).
- 🔄 **1-Click Bulk Renewal**: Instantly renew all active members into the next month cycle with new serial numbers and valid date ranges.
- 👥 **Members Directory**: Full member profiles with CNIC, phone numbers, routes, and vehicle numbers.
- 🖨️ **Print Support**: Print single pass cards or entire batch print sheets.
- 💾 **Offline Database**: Powered by browser IndexedDB (no remote server or database required).
